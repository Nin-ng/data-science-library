## ⚡ The Data Science Autopilot

Most Data Science problems can follow a similar process:

| Step            | Question                               |
| --------------- | -------------------------------------- |
| **1. Question** | What problem are we trying to solve?   |
| **2. Data**     | What data do we have?                  |
| **3. Check**    | Is the data complete and usable?       |
| **4. Explore**  | What patterns and relationships exist? |
| **5. Explain**  | What factors appear to matter?         |
| **6. Predict**  | Can we predict the outcome?            |
| **7. Decide**   | What should we do with the result?     |

## 🎯 Philosophy

### Practice over memorization

Learn by solving problems.

### Reuse over repetition

If a workflow works, turn it into a template.

### Start simple

Build a baseline before adding complexity.

### Insights over models

A model is useful when it helps answer a meaningful question.

### Automate what repeats

The long-term goal is to turn common Data Science tasks into an **Autopilot**.

4. Upload your dataset.
5. Run the workflow.
6. Investigate the interesting patterns.
7. Modify the template for your problem.
